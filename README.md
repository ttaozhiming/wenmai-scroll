# 文脉长卷

**作业路线：路线二 · Agent 辅助编程 / 视觉网站**

一座现代水墨风格的线上人物展厅。沿着时代认识屈原、司马迁、陶渊明、李白、杜甫、王安石、苏轼、李清照和辛弃疾。人物解说用原创、轻松的语言讲述；引文可在人物手札里点开原文核对。视觉元素由 CSS 和 SVG 编写，没有使用现成网站模板。

## 特色与功能

- 按先秦、汉晋、唐、宋筛选人物，或搜索人物、作品、时代。
- 点开人物手札，阅读生平、作品短句、赏析和史料小注；支持上一位、下一位及键盘方向键切换。
- 收藏人物，查看“我的书签”和最近阅读足迹；数据仅保存在当前浏览器。
- “偶遇一位”随机打开人物；提供无搜索结果、空书签和操作成功提示。
- 适配电脑与手机，并为键盘操作和减少动画偏好提供支持。

## 技术栈与结构

- **Vite 8 + React 19 + JavaScript + CSS**，纯前端，不需要服务器或账号。
- `src/figures.js`：九位人物的资料、作品短句和原文链接。
- `src/App.jsx`：筛选、搜索、人物详情、收藏、阅读足迹等交互。
- `src/styles.css`：现代水墨风格、响应式布局和动画。
- `vite.config.js`：本地开发与 GitHub Pages 的网站路径。
- `.github/workflows/deploy.yml`：上传到 GitHub 后自动构建并发布。
- `PUBLISH_GUIDE.md`：面向初学者的 GitHub 网站点击步骤。
- `screenshot.png`：电脑尺寸效果截图。

## 本地运行

需要 **Node.js 22.12 或更新版本**（本项目使用 Node.js 24.19 验证）。在项目文件夹打开终端后运行：

```bash
npm ci
npm run dev
```

浏览终端给出的本地地址，通常是 `http://localhost:5173/wenmai-scroll/`。检查正式构建可运行 `npm run build`，产物在 `dist/`；用 `npm run preview` 预览正式构建。

## 检查结果与已知限制

已完成 `npm run build`，构建成功；正式构建也已在 `/wenmai-scroll/` 路径打开，确认资源加载正常。在浏览器中检查了手机和电脑布局、时代筛选、无结果提示、人物详情、收藏、阅读足迹以及刷新后收藏仍在；浏览器控制台未见错误。作品原句分别核对了各人物手札所链接的原文页面。

当前浏览器的收藏和足迹不会同步到其他设备；清除浏览器网站数据后会消失。若浏览器禁止本地存储，页面仍可浏览，但收藏和足迹只在本次打开期间有效。**GitHub Pages 线上发布尚待上传仓库后验证。**

## 验收时可以这样解释

- **状态在哪里？** 当前筛选、搜索词、打开的人物、收藏列表和阅读足迹保存在 `App.jsx` 的 React 状态；收藏和足迹还会写入浏览器 `localStorage`。
- **点击后发生什么？** 筛选和搜索会重新计算显示的人物；点人物会设置当前人物并更新足迹；点星星会增删收藏并显示提示。
- **如何修改内容？** 在 `src/figures.js` 改人物对象中的 `story`、`quote`、`source` 等字段，保存后页面会更新。
