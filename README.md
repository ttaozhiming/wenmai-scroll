# 文脉长卷

**作业路线：路线二 · Agent 辅助编程 / 视觉网站**

一座现代水墨风格的线上人物展厅。沿着时代认识屈原、司马迁、陶渊明、李白、杜甫、王安石、苏轼、李清照和辛弃疾。首页是一幅可探索的长卷；点击人物卡片先翻开人物手札，阅读生平、诗句赏析和史料小注，再点醒目的“深入了解”进入该人物的对话故事页。故事用轻松的旁白和情境化人物对白讲生平、代表作品与文化影响，并把作品原句单独标出。页面里的人物形象是九张不同的原创水墨画，参考课本插画的朴素笔触，**不是真实肖像，也没有复制教材图片**。

## 特色与功能

- 首页保留纸墨配色、人物卡片和长卷布局；可按时代筛选，搜索人物、作品、时代，或随机“偶遇一位”。点击卡片、书签或阅读足迹会打开人物手札抽屉。
- 手札保留“卷内阅读”“细读一句”“史料小注”和收藏、切换人物；顶部新增红色“深入了解”入口，进入对应的对话故事页。
- 每位人物有可分享、可刷新的独立网址，例如 `?person=su-shi`。故事分三章，有逐句阅读、上一句、跳过本章、一次双选回应、卷末小结和作品原文链接。
- 故事页支持浏览器返回键、返回长卷、从头再读、遇见下一位；配有适合该人物的原创水墨图像。图片加载失败时显示人物文字印记。
- 可收藏人物，查看“我的书签”和最近阅读足迹；只存于当前浏览器。空搜索、空书签、未知人物链接和本地存储不可用都有提示或回退。
- 适配电脑与手机；键盘可用左右方向键切换对白，减少动画偏好会跳过打字效果。

## 技术栈与项目结构

**Vite 8 + React 19 + JavaScript + CSS**，纯前端，不需要账号或后端。项目没有使用现成网站模板，首页山水由 SVG 和 CSS 绘制，人物图像为本项目原创生成素材。

| 文件或目录 | 作用 |
| --- | --- |
| `src/figures.js` | 九位人物的基础资料、作品原句和原文链接 |
| `src/stories.js` | 九篇三章节故事、对话、回应选项和小结 |
| `src/App.jsx` | 首页、筛选搜索、书签足迹、网址和浏览器历史 |
| `src/DetailPanel.jsx` | 人物手札抽屉、深入了解入口、收藏和人物切换 |
| `src/StoryPage.jsx` | 人物页的逐句阅读、选择、图片回退及键盘操作 |
| `src/styles.css`、`src/detail.css`、`src/story.css` | 首页、手札和故事页的纸墨视觉、手机布局 |
| `public/portraits/` | 九张压缩后的原创 WebP 水墨图像 |
| `vite.config.js` | GitHub Pages 的 `/wenmai-scroll/` 基础路径 |
| `.github/workflows/deploy.yml` | 上传到 GitHub `main` 分支后构建并发布 |
| `PUBLISH_GUIDE.md`、`AI_USE.md` | 更新现有仓库的步骤、真实的 AI 协作记录 |
| `screenshot.png` | 保持原样的首页效果截图 |

## 本地运行

需要 **Node.js 22.12 或更新版本**；本地用 Node.js 24.19 验证。进入项目文件夹后运行：

```bash
node -v
npm ci
npm run dev
```

打开终端显示的地址，通常是 `http://localhost:5173/wenmai-scroll/`。正式构建和预览：

```bash
npm run build
npm run preview
```

构建结果在 `dist/`。不要双击 `index.html` 以 `file://` 方式打开，它需要由 Vite 启动或由 GitHub Pages 发布。本机默认 `node` 若仍是 19 版，会因版本不足而无法运行 Vite 8；先切换到 Node.js 22.12+ 再执行上述命令。

## 功能检查与结果

在本地使用 Node.js 24.19 完成 Vite 正式构建，并在 `/wenmai-scroll/` 路径预览。浏览器检查了：

1. 首页电脑与 390×844 手机布局；故事页手机布局没有横向溢出。
2. 九个人物网址直接打开时，标题、章节和各自的水墨图像均正常加载；辛弃疾的直达链接刷新后仍可阅读。
3. 苏轼篇从对话、回应选项读到小结，作品链接可见；收藏后返回长卷，书签计数更新，浏览器返回没有意外重开故事。
4. 不存在的人物编号（例如 `?person=unknown`）显示清楚的返回入口；浏览器控制台没有发现错误。
5. 从司马迁卡片打开手札，点击“深入了解”进入正确的人物故事页；浏览器返回后回到长卷。手札翻页、收藏和 Esc 关闭均正常。390×844 手机尺寸下，屈原手札与“深入了解”按钮完整显示，没有横向溢出。

复查其他功能可在首页搜索一个不存在的词、切换时代、收藏一位人物并刷新、打开“最近读过”，再在手机尺寸浏览人物页。**这些九篇故事的每一句和每个分支尚未逐条人工通读；线上更新版尚未上传与验收。**

已知限制：书签和阅读足迹只保存在当前浏览器；清除网站数据后会消失，禁止本地存储时只能在当前打开期间保留。作品资料链接需要联网。人物对白是原创的情境化表达，不应当作历史人物原话；只有标明“作品原句”的句子是引文。

## 验收时可以这样解释

- **状态在哪里？** 当前筛选、搜索、打开的手札、故事人物、故事进度、收藏和阅读足迹分别由 `App.jsx`、`DetailPanel.jsx` 和 `StoryPage.jsx` 的 React 状态管理；收藏与足迹还会写进 `localStorage`。
- **点击人物后发生什么？** 卡片点击先在 `App.jsx` 设置手札人物，`DetailPanel.jsx` 展示三段阅读内容；点“深入了解”后，`App.jsx` 把人物 ID 写到网址的 `person` 参数，`StoryPage.jsx` 读取对应故事和图像。浏览器返回键回到长卷。
- **如何判断故事结束？** `StoryPage.jsx` 把三章对白排成一列，当前序号到达对白总数时显示卷末小结；选项只改变本段回应，然后继续主线。
- **如何做现场小改动？** 修改 `src/stories.js` 某个人物的对白或选项，保存后 Vite 会立即刷新；修改人物资料和原文链接则在 `src/figures.js`。
